name: pr-status
description: "Itemize the GitHub PRs of a project that need work from the user: unaddressed comments on their PRs, pending review requests, and approved PRs waiting to merge. Use when asked what PRs need attention, for a PR triage, or for PR status."
---

Check all PRs related to this project and itemize all PRs that require work from the user.

This includes, but is not limited to:
- PRs by the user that have comments that have not been addressed.
- PRs from other users that have requested a review from the user and this review has not been done yet, or still needs to address something.
- PRs by the user that have been approved and have to be merged.
