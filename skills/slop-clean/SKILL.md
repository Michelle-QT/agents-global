## Slop

Slop is content (text, code, ...) that is incorrect, meaningless, irrelevant/out-of-scope, unconventional (does not follow the conventions of its document or codebase), one-off, outdated, repeated, or unnecessary.

## Workflow

- Read all documents specified by the user in search for slop.
- To determine if something is or is not slop, read all other relevant documents.
- Propose to the user how to address the slop.
- Once the user agrees, proceed to clean it.
